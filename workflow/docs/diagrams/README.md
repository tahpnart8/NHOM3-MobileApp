# Sơ đồ mô hình hóa chức năng

Giai đoạn 1 của đồ án, dựa trên bảng đặc tả chức năng ở [`../product/dac-ta-chuc-nang.md`](../product/dac-ta-chuc-nang.md). Cả ba sơ đồ chỉ vẽ các chức năng **Đợt này**; chức năng **Phát triển sau** không có trên sơ đồ.

| Sơ đồ | Thư mục | Người phụ trách |
| --- | --- | --- |
| Sơ đồ chức năng (cây chức năng toàn hệ thống) | [so-do-chuc-nang/](so-do-chuc-nang/README.md) | |
| Sơ đồ lớp (OOP, chia gói theo tầng) | [so-do-lop/](so-do-lop/README.md) | |
| Sơ đồ quan hệ thực thể (ERD, Firestore và Room) | [erd/](erd/README.md) | |

Mỗi thư mục có file `.drawio` gốc (mở được bằng draw.io desktop hoặc app.diagrams.net), ảnh `.png` xuất ra để xem nhanh, và một `README.md` tóm tắt nội dung.
