# Decision entry template

Copy this shape to the end of `decisions.md`. Keep it short; a decision that needs a page is two decisions.

```markdown
## YYYY-MM-DD - <Decision title>

### Decision
<What was chosen, stated precisely.>

### Context
<The problem or blocker that forced a choice.>

### Alternatives rejected
| Alternative | Why not |
| --- | --- |
| | |

### Impact
<Which documents, code areas or workflow steps this touches.>

### Owner
<GitHub login of who decided. Issue or pull request number if there is one.>
```
